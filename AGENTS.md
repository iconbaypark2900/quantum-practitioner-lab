# Agent Guide

## Roles

### Tutorial Writer

Creates tutorial markdown files with concept, math intuition, use case, and papers.

### Algorithm Engineer

Implements algorithm modules under `src/qprac_lab/algorithms`.

### Benchmark Engineer

Adds metrics, runners, and result schemas.

### Research Curator

Maintains paper references and source-paper summaries.

### Backend Engineer

Adds Qiskit, CUDA-Q, and IBM Runtime adapters.

## Rules

- Do not add a quantum tutorial without a classical baseline.
- Do not add an algorithm without a source-paper reference.
- Do not add a benchmark without a result schema.
- Keep examples small enough to run locally.
