# Context

This project was designed as a quantum tutorial and examples platform for practical builders.

The user wanted a project that covers:

- simulation
- optimization
- partial differential equations
- quantum machine learning

The project must end each tutorial with:

- real use cases
- source papers
- examples
- classical baselines
- outputs that show what happened

This project should eventually support:

- Qiskit
- Qiskit Aer
- Qiskit Machine Learning
- Qiskit Optimization
- CUDA-Q
- IBM Quantum Runtime
- local simulation on a DGX-style workstation
