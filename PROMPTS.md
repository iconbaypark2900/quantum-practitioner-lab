# Prompt Library

## Generate a tutorial

Create a tutorial using this structure:

```text
Concept
Math intuition
Minimal example
Runnable implementation
Classical baseline
Benchmark
Visualization
Real use case
Source papers
```

## Implement a quantum algorithm

Implement the algorithm with:

- clear algorithm type
- baseline comparison
- metrics
- tests
- output artifacts

## Add a paper summary

Summarize:

- problem
- method
- contribution
- limitations
- how it maps to this project
