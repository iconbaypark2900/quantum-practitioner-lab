# Benchmark Methodology

## Rule

Do not claim a quantum method is useful unless it is compared against a classical baseline.

## Metrics

### Simulation

- energy error
- convergence steps
- circuit depth
- runtime

### Optimization

- objective value
- approximation ratio
- constraint violations
- runtime

### PDEs

- L2 error
- residual loss
- runtime

### QML

- ROC-AUC
- F1
- accuracy
- kernel alignment
- train time
