# Tutorial 3: Quantum Kernel for Biomedical Classification

## Use case

Biomedical KG link prediction.

## Algorithm type

Kernel method / QSVC.

## Classical baselines

- RBF-SVM
- XGBoost
- Random Forest

## Source paper

- Havlíček et al., "Supervised learning with quantum-enhanced feature spaces"

## Required output

- ROC-AUC
- F1 score
- Accuracy
- Kernel matrix visualization
- Baseline comparison table

## Real use case

Predict likely missing links in biomedical graphs, such as:

- drug-disease links
- gene-disease links
- protein-protein interaction links
- compound-target links
